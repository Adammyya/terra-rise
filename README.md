# TerraRise

### Deep Learning Super-Resolution Mapping for Medium-Resolution Satellite Imagery

> **SIH26142 — Deep Learning Based Super Resolution Mapping (SRM) from Medium Resolution Satellite Imageries**

TerraRise is a scientific Earth-observation workstation designed to enhance medium-resolution satellite imagery using **deep-learning-based super-resolution**, while keeping model uncertainty, validation quality, and geospatial context visible to the user.

The project is being developed for applications such as urban analysis, agriculture, land-cover interpretation, localized infrastructure inspection, and disaster assessment.

---

## 🌍 The Problem

Medium-resolution Earth-observation imagery provides:

- wide geographic coverage
- frequent revisit opportunities
- valuable information for land-cover and environmental monitoring

However, its spatial detail can be insufficient for identifying:

- small buildings
- narrow roads
- field boundaries
- localized damage
- small urban structures
- fine-scale landscape features

This creates a need for methods that can reconstruct higher-resolution representations from existing medium-resolution imagery.
