## Source quality

Prefer:
1. peer-reviewed papers
2. official mission/instrument documentation
3. official dataset documentation
4. established technical standards
5. reputable research repositories

Do not present generated text as a scientific source.

## Entry format

```text
Title:

Year:
Venue / organization:
URL / DOI:

```

## Citation discipline

A source should only be used to support a claim that it actually establishes. Avoid presenting unrelated benchmark results as SatQuery performance.
